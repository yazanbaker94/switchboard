# Visual assets

- `whatsapp-split-view.png` is the supplied Switchboard illustration, copied unchanged. It clearly shows separate Personal and Work WhatsApp Web panes. It contains sample names, conversations, and avatars; it is an illustrative preview, not a capture of signed-in accounts.
- `hero-whatsapp.png` is supplemental brand artwork created with the built-in image-generation tool using that illustration as a reference. It explicitly presents two WhatsApp accounts with sample chat content.
- Both images were visually reviewed for private contact details and inspected for embedded metadata. Neither includes phone numbers, email addresses, QR codes, local paths, session storage, or real profile photographs.
- The browser development fixture remains available through `npm run demo`. Its simplified messaging panes are a development utility rather than the product's promotional screenshots.

The final banner prompt is recorded below. The reference image is the supplied illustration included beside this file.

```text
Use case: ads-marketing
Asset type: wide 16:9 GitHub product banner for Switchboard, an unofficial Windows wrapper for TWO WHATSAPP ACCOUNTS.
Input image 1: product reference; preserve its clearly recognizable WhatsApp Web visual identity. The user wants the messaging service itself to be obvious.
Primary request: Create a polished editorial product banner with dark charcoal, subtle purple Personal accents, amber Work accents, and unmistakable WhatsApp green. On the left use the exact title "Switchboard", then the exact headline "Two WhatsApp accounts." and below it the exact supporting line "One workspace." Large legible white type, emphasize WhatsApp in its recognizable bright green. Small exact line "Personal + Work · Windows".
On the right, show a clean front-facing desktop app window faithful to the reference image: narrow dark Switchboard account rail, Personal and Work color-coded account cards, and TWO SIDE-BY-SIDE WHITE/LIGHT WHATSAPP WEB PANES. Each pane must prominently say "WhatsApp" in green and include the familiar green WhatsApp speech-bubble telephone mark. Show WhatsApp's familiar pale beige doodle chat wallpaper, green outgoing bubbles, white incoming bubbles, chat list and rounded bottom compose bar. Include visible labels "Personal" and "Work" above their respective panes. Use only short fictional UI labels "Sample chat" and short sample bubbles "Hello!" / "See you soon." No actual people or avatar photos. Keep the reference app's tidy dark frame and clear two-account concept. This must read as WhatsApp, not a generic dark messaging service.
Style: crisp realistic flat product mockup set in a restrained premium dark background, minimal perspective, sharp white/green screens, subtle soft shadows, modest purple/amber corner accents. Do not let screens become too small. No irrelevant shapes. Not a screenshot claim, this is illustrative product art.
Text (verbatim): "Switchboard"; "Two WhatsApp accounts."; "One workspace."; "Personal + Work · Windows"; "Personal"; "Work"; "WhatsApp".
Privacy constraints: No personal contact details, phone numbers, email addresses, QR codes, private messages, usernames, local paths or real faces. Only fictional sample chat content. Do not copy the named contacts or conversations from the reference. No "official", no verification seals, no affiliation claims, no watermark.
```
